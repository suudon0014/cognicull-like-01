# Cognicull Relativity - 前提知識ツリー学習 Web アプリケーション

Cognicull（コグニカル）に着想を得た、**特殊相対性理論および一般相対性理論**を学べる有向非巡回グラフ（DAG）ベースの前提知識ツリー学習Webアプリケーションです。

---

## 🌟 特長・主要機能

1. **動的プルーニング（枝刈り）エンジン**:
   - 任意のノードを「習得済み」にすると、その上流の前提概念が自動的に「習得済み」としてマークされます。
   - 不要になった前提ノードはツリー上で「プルーニング済み（枝刈り完了）」として縮退・減光表示されます。
   - 選択されたターゲットノードに至る未習得負荷率（%）を **HUD メーター** にてリアルタイム表示します。

2. **インタラクティブ前提ツリービュー (Core UX)**:
   - D3.js + SVG によるズーム・パン対応の動的DAGツリー可視化。
   - ノード状態（ターゲット 🎯 / 学習可能 ★ / 習得済み ✓ / プルーニング ✂ / ロック中 🔒）を直感的に識別。

3. **トピックリーダー (Micro-Learning)**:
   - コンパクトな解説文と **KaTeX** による数式レンダリング。
   - 即時解説フィードバック付きのセルフチェッククイズ。
   - 「理解した（ツリーを刈り込む）」ボタンでの1クリック学習更新。

4. **全体タクソノミー & 検索ビュー**:
   - 30個の物理学ノードを階層レベル・カテゴリ別に整理。
   - キーワード検索およびステータス/カテゴリフィルタリング。

5. **クライアント永続化 & データ移動**:
   - `localStorage` への自動保存と復元。
   - JSON形式での進捗インポート/エクスポートおよび完全リセット機能。

## 🚀 ローカル開発環境の起動手順

### 1. 依存関係のインストール
```bash
npm install
```

### 2. DAG データ整合性検証スクリプトの実行
```bash
npm run validate-dag
```

### 3. 開発サーバーの起動
```bash
npm run dev
```

### 4. 単体テストの実行
```bash
npm run test
```

### 5. プロダクションビルドの確認
```bash
npm run build
npm run preview
```

## 🌐 GitHub Pages への公開手順 (GitHub Actions)

本リポジトリには `.github/workflows/deploy.yml` が含まれており、`main`（または `master`）ブランチへプッシュすると自動で GitHub Pages へデプロイされます。

### 有効化手順:
1. リポジトリを GitHub へプッシュします:
   ```bash
   git push origin main
   ```
2. GitHub のリポジトリページで **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Source** を **GitHub Actions** に設定します。
4. Actions タブでワークフローの完了を確認すると、`https://<username>.github.io/<repository-name>/` にてアプリが公開されます。
